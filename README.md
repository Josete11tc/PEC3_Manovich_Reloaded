# PEC3: Releyendo la hibridación digital con las gafas de Manovich

#### Recurso de aprendizaje de Cultura Digital

#### Autor: Jose Carlos Fernandez Molina

#### Fecha: Mayo 2026

## Planteamiento

Lev Manovich, en El software toma el mando (2013), propone una idea especialmente útil para analizar la cultura digital actual, el software ya no se usa solo como una herramienta para usar medios que ya existen, sino como el espacio donde esos medios se transforman y se combinan de maneras nuevas.
Desde esta perspectiva, podemos ver que lo más importante no es que medios aparecen en una aplicación o en una plataforma, sino cómo sus técnicas se integran mediante software para generar una experiencia distinta.

Esta cuestión es importante porque no debe confundirse la hibridación con la multimedia. El entorno de multimedia, se compone de imagen, texto, sonido o vídeo que conviven en un mismo espacio, pero no necesariamente se transforman entre sí; en la hibridación, en cambio, los lenguajes y operaciones de varios medios se unen hasta producir una nueva lógica cultural y una nueva forma de interacción.
La hibridación no es una suma de capas, sino una integración más profunda entre medios, interfaces y técnicas.

Esta hibridación, podemos verla desde dos puntos de vista diferentes, por un lado, cuando el software ofrece nuevas formas de representar el mundo manipulando datos, imágenes o modelos; y por otro lado, cuando transforma la interfaz y propone nuevas formas de navegar o interactuar.

En este ensayo voy a analizar dos casos: Nano Banana y PlayStation VR2. He escogido estos casos porque son actuales, fáciles de entender y permiten estudiar dos formas distintas de hibridación, una relacionada con IA y otra a la inmersión interactiva de los videojuegos.
